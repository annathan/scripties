# Background music

Drop `.mp3` / `.wav` / `.m4a` files in this folder. `video_generator.py`
picks one at random and mixes it under each generated video's audio.

**Only use tracks you're licensed to monetize on YouTube.** Good sources:

- [YouTube Audio Library](https://www.youtube.com/audiolibrary) (built for this — free, cleared for monetized YouTube use)
- A royalty-free library with an explicit commercial/YouTube license (Epidemic Sound, Artlist, etc. — paid subscriptions)
- Music you generated yourself with a tool whose output you own the rights to

Do not pull tracks from other videos, generic "royalty free" YouTube rips, or
anything without a clear commercial license — this is one of the fastest
ways to get a Content ID claim or copyright strike, which can also block
monetization on the channel.

This folder is gitignored (except this file) since licensing is per-file
and shouldn't be assumed transferable by committing it to the repo.
